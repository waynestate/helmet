Put it on before you ship.

HELMET is one small PHP package with no framework underneath. Before your app serves its first page, it sends the security headers, hardens the session, checks that the request really came over HTTPS, answers /up and sets up JSON logs. Raw PHP, Laravel and PSR-15 apps all wear the same one, so they send the same headers.

composer require waynestate/helmet

Already included in WELD and in every Sourdough app. Use HELMET on its own to add the security headers and a hardened session to an app you already have.

01

The playbook

Each play is one protection and the attack it stops. Laminated, because coffee happens on the sideline.

  1. 22

    Play 22: Nonce Dive

    CSP

    Blocks Injected script (XSS)

    A fresh nonce on every response, plus strict-dynamic. A script without the nonce does not run, and there is no 'unsafe-inline' or 'unsafe-eval' to sneak through.

    script-src 'self' 'nonce-…' 'strict-dynamic'

    New nonce every snap.

  2. 34

    Play 34: Frame Screen

    FRAMES

    Blocks Clickjacking

    frame-ancestors 'self' in the policy, and X-Frame-Options for older browsers. A stranger's page cannot frame yours and trick a click.

    X-Frame-Options: SAMEORIGIN

    No strangers in the frame.

  3. 47

    Play 47: Long Snap

    HSTS

    Blocks A downgrade to plain HTTP

    The default is one year and covers subdomains, and HELMET sends it only when the request really was HTTPS. Start with a short max-age and raise it once nothing breaks. preload is the domain owner's call, so HELMET never adds it.

    Strict-Transport-Security: max-age=31536000; includeSubDomains

    Start short, then go long.

  4. 41

    Play 41: Session Lock

    SESSION

    Blocks Session fixation and cookie theft

    HELMET turns on strict mode, cookie-only session IDs, HttpOnly and SameSite=Lax before the session starts. Secure follows the request; on Citadel, where TLS ends at the proxy, set HELMET_SESSION_SECURE=always. It won't run once a session is already active, because changing these mid-session does nothing.

    session.use_strict_mode=1 cookie_httponly=1 cookie_samesite=Lax

    Strapped before kickoff.

  5. 58

    Play 58: Proxy Trap

    PROXIES

    Blocks A forged X-Forwarded-Proto

    HELMET believes X-Forwarded-Proto only when it comes from a trusted proxy's address. A spoofed one from the internet is ignored, and no HSTS goes out on a request that wasn't really secure. List the proxy's own address, never a whole private range.

    helmet_boot(['preset' => 'citadel'])

    The Unsung hero of the line.

  6. 00

    Play 00: Victory Formation

    /UP

    Blocks A slow app called dead

    GET or HEAD /up answers 200 ok with Cache-Control: no-store before your code runs, so the load balancer sees a live container even while the app is busy.

    GET /up → 200 ok

    Take a knee. Still up.

Equipment check: the headers on every response

SecurityHeaders::build() makes these seven for raw PHP and Laravel alike, and a test checks that both send the same names and values. Cross-Origin-Resource-Policy stays on the bench until you turn it on.

  • Content-Security-Policythe WayneUI default policy, a fresh nonce and strict-dynamic
  • X-Content-Type-Optionsnosniff
  • X-Frame-OptionsSAMEORIGIN
  • Referrer-Policystrict-origin-when-cross-origin
  • Permissions-Policycamera=(), geolocation=(), microphone=(), payment=(), usb=()
  • Cross-Origin-Opener-Policysame-origin, configurable
  • Strict-Transport-Securityone year with includeSubDomains, on HTTPS only

Even on a fumble. The middleware still sends the headers when the inner handler throws, and X-Powered-By is stripped from every response. Milquetoast is a Helmet song. It is not a Content-Security-Policy.

Raw PHP

  1. 1

    Step 1: Strap it on

    It's one Composer package, and it doesn't need a framework.

    composer require waynestate/helmet
  2. 2

    Step 2: Call helmet_boot() at the top

    Put it first in your front controller, before anything is echoed. This one call sends the headers, hardens the session, checks the proxy and answers /up.

    use function Waynestate\Helmet\helmet_boot;

$helmet = helmet_boot(['preset' => 'citadel']);
  3. 3

    Step 3: Nonce your inline scripts

    $helmet['nonce'] is this request's nonce. If you use Vite, the meta tag lets its runtime use the nonce too.

    echo helmet_csp_nonce_meta($helmet['nonce']); // in <head>

<script nonce="<?= $helmet['nonce'] ?>">…</script>

Laravel

  1. 1

    Step 1: Strap it on

    Package discovery registers the provider and both middlewares. Nothing to add to bootstrap/providers.php.

    composer require waynestate/helmet
  2. 2

    Step 2: Publish config/helmet.php

    Change the CSP there, where it's a PHP array. In .env it would have to be escaped JSON.

    php artisan vendor:publish --tag=helmet-config
  3. 3

    Step 3: Set the platform in .env

    Keep health: '/up' in withRouting(), because the adapter adds no route of its own. @vite already carries the nonce.

    HELMET_PRESET=citadel

PSR-15

  1. 1

    Step 1: Strap it on

    The same core, mounted in a middleware pipeline.

    composer require waynestate/helmet
  2. 2

    Step 2: Line up the middleware, /up first

    The health check goes first, then the headers. The headers still go out when the inner handler throws.

    $factory = new Psr17Factory();
$proxies = new TrustedProxies(Presets::proxies('citadel'));

$middleware = [
    new HealthCheck($factory, $factory, '/up'),
    new SecurityHeadersMiddleware($proxies),
];
  3. 3

    Step 3: Read the nonce downstream

    Your handlers get the same nonce the CSP header carries, from a request attribute.

    $request->getAttribute('helmet.csp_nonce')

Off the WSU platform? Skip the preset and list the one address your front proxy connects from, for example 'trusted_proxies' => ['203.0.113.10']. Never a whole private range: a broad range also trusts the other containers on the network. An unknown preset name throws at boot, so a typo fails loudly instead of trusting nothing.

The film room

What HELMET writes down while the game is on, so you can watch the tape afterwards.

  1. Reel 1

    Logs, one line each

    {"message":"login failed",
 "context":{"user":"student42",
  "password":"***"},
 "level_name":"WARNING",
 "channel":"app"}

    Monolog JSON, one event per line, each with a request ID. Passwords, tokens and session IDs come out as ***. If the log file can't be written, HELMET writes to stderr and the request carries on.

  2. Reel 2

    Version warnings

    Laravel 11 is end of life and
no longer receives security
updates. Upgrade to a
supported version.

    Point HELMET_POLICY_PATH at CREED's policy.json and the ribbon warns about a PHP or Laravel version in its security-only phase or past end of life. An active or unknown version gets no warning, and a missing file never breaks the page.

  3. Reel 3

    Metrics, off by default

    # HELP helmet_info HELMET is running.
# TYPE helmet_info gauge
helmet_info{php_version="8.4",
 helmet_version="0.2.5"} 1

    A Prometheus endpoint you turn on with HELMET_METRICS_ENABLED. It needs a bearer token or an IP allow list; with neither, it answers 404 and logs a warning. Nothing scrapes it yet.

  4. Reel 4

    The ribbon

    staging

    In local, dev, testing and staging, Laravel apps get <div class="helmet-ribbon"> right after <body>, so nobody mistakes the scrimmage for the game. It never shows in production or on JSON responses. No Aftertaste.

Coach's rules for Vite and Inertia

The CSP stays honest only if the bundle plays along.

  1. Nonce every inline script. There is no 'unsafe-inline' for scripts; @vite tags already carry the nonce.
  2. No 'unsafe-eval'. If your bundle needs eval, fix the bundle.
  3. No scripts in Inertia's <Head>. They render after load without the nonce, and the browser blocks them. Put scripts in the layout.
  4. One nonce per request, from one package. A second Vite::useCspNonce() splits the header from the tags; HELMET logs a warning when it sees one.
  5. No shared caching of nonced HTML. A cached page carries yesterday's nonce. Repetition is a fine Helmet song and a terrible nonce.
